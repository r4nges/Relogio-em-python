# Relogio-em-python
Relógio feito em python, objetivando o estudo da linguagem.

Como funciona:
Importa a biblioteca tkinter e chama de tk
Importa uma de suas funções, de horário
Cria a classe do relógio que serão feitas as configurações de fonte, posição na tela e alteração
Define o horário da máquina e diz que a cada 1000ms, ele irá repetir o comando e atualizar
Atribui a janela à biblioteca de GUI
